# Project-in-Statistics w/ additional coding file

Code used regarding the course Project in Statistics 25/26. 

The project goal was to understand the SDE Strang Splitting Scheme, and the Student Kramers Oscillator. This was done based on building blocks: 
Firstly it was computed the likelihood for complete data and evaluated using a simulation study. This was only done to the constant noise setting. It is not difficult to implement the same for the non additive setting. 
Secondly some modifications were made in order to fit the likelihood to real data - where the velocity is not observed.
Lastly some models were compared and evaluated in the real data setting.

This is the order that one can find in the R Markdown. This is to be read by someone with knowledge in basic SDE's.

Suggestions and comments are welcome :)
